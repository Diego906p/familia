💜 1. ¿Qué es esta app?

Es una aplicación web para acompañar a Luanna en el desarrollo de hábitos, responsabilidades y aprendizaje. No es una agenda ni un sistema de control: es un espacio personal donde ella ve su esfuerzo reflejado de forma positiva y motivadora.

La idea principal es que pueda compararse consigo misma y ver cuánto ha avanzado con el tiempo. La recompensa es el progreso visible: estrellas acumuladas, rachas, niveles y logros. No castiga incumplimientos ni mide rapidez.

🏗️ Es un sitio estático (solo HTML, CSS y JavaScript), pensado para publicarse gratis en GitHub Pages y verse desde la tablet de Luanna o el celular de papá.

Cambiar una contraseña

📝 4. Uso diario (papá)

Esta es la rutina de cada día desde el Panel de Administración:

  • 1Entra como Papá y selecciona la fecha (por defecto, hoy).
  • 2Marca cada actividad como Realizado ✔ o No realizado ✖ (ver sección 5).
  • 3Opcional: escribe una observación, la lectura realizada o el tema de matemáticas.
  • 4Pulsa 💾 Guardar día.
  • 5Pulsa 📤 Publicar cambios para que Luanna lo vea desde su tablet.

Mensajes motivadores

Papá puede dejar mensajes (“Estoy orgulloso de tu esfuerzo”, etc.). Aparecen destacados en el panel de Luanna.

Estadísticas e historial

El panel muestra estrellas totales, días completos, rachas, semanas perfectas, nivel actual, y un historial con un selector que permite ver cualquier mes registrado (no solo los últimos 30 días).

📤 6. Publicar cambios en GitHub

Como el sitio es estático, los datos viven en data/data.json. El botón 📤 Publicar cambios sube ese archivo directo al repositorio usando la API de GitHub; en 1–2 minutos se actualiza en todos los dispositivos.

Esto requiere configurarlo una sola vez por navegador en la tarjeta ⚙ Publicación en GitHub (botón Configurar):

TokenLa “llave” github_pat_… (ver sección 7)
✅ Si todo está bien, al publicar aparece: “✔ Publicado: en 1-2 min se verá en todos los dispositivos”.

🗝️ 7. Crear el token de GitHub

El token es una llave que le permite a la página escribir en tu repositorio. Se crea una vez:

  • 1Entra a github.com/settings/personal-access-tokens/new
  • 2Token name: panel-luanna · Expiration: Custom, dentro de 1 año.
  • 3Repository access: “Only select repositories” → elige el repo familia.
  • 4En Repository permissions → Contents → ponlo en “Read and write”.
  • 5Pulsa Generate token y copia el código github_pat_… (solo se muestra una vez).
  • 6Pégalo en el campo Token del panel y pulsa 💾 Guardar.
🔒 El token es como una contraseña: nunca lo subas al repositorio ni lo compartas. Se guarda solo en tu navegador. Por eso lo limitamos a un repo y un solo permiso.

🖼️ 9. Sistema de imágenes

Todas las ilustraciones se definen en js/images.js, apuntando al repositorio de imágenes en GitHub. Para cambiar un gráfico basta reemplazar el archivo en ese repo (mismo nombre).

Variantes por ánimo

Algunas imágenes tienen 3 versiones (1 = bien · 2 = medio · 3 = bajo) que cambian solas según el desempeño:

  • avatar_luanna, star_happy, trophy → según el % de la semana
  • flame_streak, cat_streak → según la racha (el hielito ❄️ es la variante 3)
  • avatar_papa → reacciona en el panel de administración
🔁 En js/images.js, USE_REMOTE_IMAGES = true usa el repo de GitHub; ponlo en false para usar la carpeta local img/.

💾 10. Cómo se guardan los datos

Cuando papá guarda un día, los datos quedan primero en el navegador (almacenamiento local). Al pulsar Publicar cambios, se suben a data/data.json en el repositorio.

El panel de Luanna lee ese data.json publicado, por eso ella ve los cambios desde cualquier dispositivo una vez publicados.

Respaldo manual

En la barra sobre el historial están ⬇ Exportar (descarga el data.json) e ⬆ Importar (carga uno guardado). Útil como copia de seguridad.

🌐 Si registras un día y no publicas, los datos siguen en tu navegador, pero la tablet de Luanna no los verá hasta que pulses Publicar cambios.

🎨 11. Pizarra colaborativa

Un módulo tipo pizarra para trabajar en tiempo real, ideal para resolver ejercicios o explicar matemáticas sobre una imagen. Se entra con el botón 🎨 Pizarra desde el panel de Luanna o el de Papá.

Herramientas

  • ✋ Mover — selecciona, mueve y (en imágenes) redimensiona con la manija de la esquina.
  • ✏️ Lápiz, 🖍️ Resaltador, 🧽 Borrador (borra el trazo que tocas), 🔤 Texto.
  • Figuras: línea, flecha, rectángulo, círculo.
  • 🖼️ Imagen — carga una o varias (ej. la foto de un ejercicio) para dibujar encima.
  • Color (8 opciones) y grosor ajustable.

Zoom y proporción

  • ➕ / ➖ / 100% para acercar, alejar y restablecer. En la tablet: pellizca con dos dedos para hacer zoom y arrástralos para desplazarte.
  • 🔓 / 🔒 bloquea la proporción al redimensionar una imagen (no se deforma).

Calculadora

El botón 🧮 abre una calculadora flotante (se puede arrastrar) para ayudarse con cálculos. Se cierra con la ✕.

Tiempo real y participantes

Todo lo que se dibuja se sincroniza al instante entre los dispositivos conectados (vía Firebase). Arriba a la derecha se ven los participantes con una luz verde = en línea o gris = desconectado. El indicador “En línea” de la barra superior confirma la conexión.

🧽 La pizarra es temporal: no se guarda nada. Cada vez que entras arranca en blanco y solo ves lo que se dibuja a partir de ese momento.

🔧 12. Mantenimiento y dudas frecuentes

Publicar en GitHub Pages (primera vez)

  1. Sube todo el contenido de la carpeta al repositorio.
  2. En GitHub: Settings → Pages → Source: main branch / root.
  3. La web queda en https://<usuario>.github.io/<repo>/ (en este caso, diego906p.github.io/familia).

Caché: ¿por qué a veces “no se ve” un cambio?

Los navegadores guardan copias de los archivos para ir más rápido. Hay que distinguir dos casos:

  • Los datos del día (estrellas, marcas) → automático El data.json se pide con una marca de tiempo única, así que siempre llega fresco. Luanna solo cierra y reabre la página (o desliza hacia abajo para recargar). No necesita Ctrl+F5.
  • El código (diseño, HTML/CSS/JS) → cambia rara vez. Lleva versión ?v=3; al subir cambios grandes de código, sube ese número en los HTML.

Cómo forzar recarga en la tablet (equivalente a Ctrl + F5)

Las tablets no tienen esa tecla. Si tras un cambio de diseño la tablet sigue mostrando lo viejo:

  • Más fácil: abre la web en una pestaña de incógnito/privada (no usa caché, carga todo fresco).
  • Borrar caché del sitio: Chrome → menú ⋮ → Configuración → Privacidad → Borrar datos de navegación → solo “Imágenes y archivos en caché” → borrar, y reabrir.
  • Recarga con tirón: desliza la pantalla hacia abajo; suele bastar para los datos.
😊 Para el uso diario no hace falta nada de esto: con la recarga normal ya aparecen las estrellas nuevas. Lo de arriba solo se usa las pocas veces que se cambia el diseño.

Responsive

La app está adaptada a móvil (≤480px), tablet (481–1024px) y escritorio (≥1025px), sin scroll horizontal y con la misma identidad visual.
